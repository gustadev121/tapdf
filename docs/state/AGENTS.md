# Current Project State — Agent Reference

This directory tracks project state. It contains two files:

- **`CURRENT.md`** — What's done, current phase, known issues, plugin inventory
- **`PLAN.md`** — Planned phases, upcoming work, file lists

Always read `CURRENT.md` first to understand where the project stands. Read `PLAN.md` to understand what comes next.

## Updating

- When a phase completes: update `CURRENT.md` (mark phase done, add completed work)
- When planning: update `PLAN.md` (add phase details, file lists)
- When starting a new phase: move relevant items from `PLAN.md` to `CURRENT.md`
